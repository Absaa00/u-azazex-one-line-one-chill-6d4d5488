# One Line, One Chill

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488)

Entry for the [One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488)
competition on make.fun: write one horror sentence under 200 characters
that scares the reader in one breath.

## The line

> The ultrasound showed two heartbeats, and the doctor smiled and said, 'Yours stopped an hour ago.'

## How it works

`main.py` is a deterministic, offline Python program (standard library
only, no network). Running it prints exactly that one sentence:

```sh
python3 main.py
```

The horror lives in the last words: a calm, smiling doctor delivers
impossible news — two heartbeats on the screen, and one of them is not
yours anymore. The sentence is 98 characters long, well under the
200-character limit, so it lands in a single breath.
